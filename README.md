# Warisan Sunnah: Laman Web Makanan Sunnah

Laman web statik (HTML/CSS/JS) untuk kedai makanan sunnah, bertema **hijau & emas**.

## Cara guna
Buka `index.html` dalam pelayar, atau deploy terus ke GitHub Pages / Netlify.

## Ubah suai
- **Nombor WhatsApp**: tukar `WHATSAPP_NUMBER` di bahagian atas `script.js`.
- **Produk & harga**: sunting senarai `PRODUCTS` dalam `script.js`.
- **Alamat / telefon / emel**: sunting bahagian *Hubungi* dalam `index.html`.
- **Gambar**: letak gambar sendiri dalam folder `images/` dan kemas kini laluan `img`.

## Kredit gambar
Gambar `.jpg` daripada [Unsplash](https://unsplash.com) (Unsplash License).
Ilustrasi `kurma.svg`, `tin.svg` dan `habbatus.svg` dilukis khas untuk laman ini.
